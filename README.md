The one line a smart fridge texts its owner at 3am — a fridge that has been
quietly logging every midnight visit and finally calls out the "just getting
water" excuse. Winner of a blind pairwise self-judge over 3 original lines,
picked for the biggest laugh and the most fridge-like voice.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (120 characters, one line, pure stdlib,
deterministic — every run is byte-identical).
